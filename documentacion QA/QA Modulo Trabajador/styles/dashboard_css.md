# Documentación línea por línea — `dashboard.css`

Archivo documentado: `views/trabajador/styles/dashboard.css`  
Módulo: Trabajador / Estilos generales del panel  
Función general: este archivo define la apariencia visual del panel del trabajador. Controla colores, fuentes, layout del sidebar, barra superior, notificaciones, hero banner, tarjetas estadísticas, tareas recientes, mensajes de asistencia, reglas responsive y animaciones de formularios.

Trazabilidad general: este CSS se conecta con las vistas PHP del trabajador como `dashboard.php`, `mis_tareas.php`, `mis_prestamos.php`, `perfil.php`, `solicitar_herramienta.php` y el include `notificaciones_panel.php`. Las clases que aparecen aquí deben coincidir con las clases usadas en esos archivos HTML/PHP. También se conecta con variables CSS globales declaradas en `:root`, con la fuente Inter cargada desde las vistas y con JavaScript que agrega o quita clases como `sidebar-open`, `notif-overlay-visible`, `notif-count`, `msg-ok`, `msg-error` o `typing-active`. Si este archivo se quita, el sistema no pierde necesariamente la lógica de base de datos, pero el panel del trabajador se vería desordenado, sin diseño, sin colores del sistema, sin responsive y con componentes visuales difíciles de usar.

Nota: no se documentan los comentarios del archivo, solo las líneas reales de CSS.

## Conclusión general del archivo

Este archivo es la base visual del módulo trabajador. No consulta base de datos y no procesa formularios, pero sí conecta directamente con todas las vistas porque les da estructura, colores, espaciados, responsive y estados visuales. Sus variables de `:root` permiten mantener el mismo verde, fondos, bordes, sombras y fuente en todo el panel. El sidebar, la topbar y la campana dependen de estas clases para verse correctamente. El include `notificaciones_panel.php` depende especialmente de las clases `notif-*`, y el dashboard depende de clases como `hero-*`, `cards-grid`, `stat-card`, `panel`, `badge-tarea`, `msg-asistencia`, `msg-ok` y `msg-error`. Si eliminas este CSS, las vistas PHP todavía podrían cargar, pero el usuario vería una interfaz sin estructura profesional, probablemente desordenada, con menús mal ubicados, notificaciones sin panel claro y poca adaptación a celular.
